*[AK]: Artifact Keeper, the artifact registry this proof of concept uses as its single source of truth
*[RKE2]: Rancher Kubernetes Engine 2, the Kubernetes distribution on the edge node
*[CNI]: Container Network Interface: the plugins that wire pod networking (canal here)
*[OCI]: Open Container Initiative: the image and registry formats container tools share
*[NEVRA]: Name-Epoch-Version-Release-Architecture, the full identity of an RPM package
*[TCG]: Tiny Code Generator, QEMU's software CPU emulator, used when KVM is not available
*[KVM]: Kernel-based Virtual Machine, Linux hardware virtualization (/dev/kvm)
